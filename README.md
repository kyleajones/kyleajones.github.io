# 3woks.com

Source for [3woks.com](https://3woks.com) — a personal site hosted on GitHub
Pages with a custom domain (DNS managed through Cloudflare).

## Structure

- `index.html` — a minimal landing page at the site root, linking out to the
  site's current featured project.
- `pick-em/` — an NFL "Pick 7" game for a small group of friends. See below.
- `.github/workflows/` — GitHub Actions automation that keeps the Pick'em
  app's data and emails running on schedule.

## Pick'em

`pick-em/` is a season-long NFL pick'em game: each week, players pick
against the spread and/or the over/under on up to 7 games, and can
optionally designate one pick as their "Lock of the Week" for a bonus if it
hits. It's a static frontend (no build step) backed by Firebase.

**Frontend** — plain HTML/CSS/JS, no framework or bundler:
- `index.html` / `matchups.js` — the picks form. Renders each week's
  matchups from `matchups.json`, along with each team's logo (`logos.json`)
  and brand color (`team-colors.json`) used to highlight a selected pick.
- `record.html` / `record.js` — the season leaderboard, plus a logged-in
  player's personal pick history and results.
- `auth.js` — Firebase Authentication: sign-up, log in, and self-service
  password reset.
- `style.css` — the shared dark theme used across all pages.

**Backend** — [Firebase](https://firebase.google.com): Authentication for
player accounts, Firestore for storing each week's picks. `firestore.rules`
enforces that players can only write their own picks, can't exceed the
7-pick weekly cap, and can't retroactively edit picks or locks for games
that have already started.

**Odds/results data** — `matchups.json` and `results.json` are generated by
two Python scripts (`update_picks.py`, `fetch_scores.py`, both backed by
`espn_api.py`) that pull the weekly schedule, spreads, totals, and final
scores from ESPN's public (undocumented, no API key required) scoreboard
API. These run on a daily schedule via `.github/workflows/update-matchups.yml`.

**Automated emails** — `pickem_common.py`, `send_reminder_email.py`, and
`send_standings_email.py` send a weekly pick reminder (Thursdays) and a
weekly standings/winner recap (Tuesdays) via [Resend](https://resend.com),
triggered by `.github/workflows/pick-em-emails.yml`. Recipients are pulled
directly from Firebase Auth, so there's no separate mailing list to
maintain.

## Deployment

Pushing to `main` deploys automatically via GitHub Pages. The custom domain
is configured through the repo's `CNAME` file, with DNS — including the
SPF/DKIM/DMARC records the Pick'em emails rely on — managed in Cloudflare.
